# Zyter UM — Nurse Demo (static site)

Single-file demo of the UM Nurse Dashboard (`index.html`).

Deployed on Render as a Static Site. `render.yaml` is a Render Blueprint —
no build step; the repo root is served as-is.

To update: replace `index.html` with the latest `um-nav.html` and push to `main`.
Render auto-deploys on every push.
